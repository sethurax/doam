# DOAM

doam is a Pycord-based Discord bot that runs Major League Redditball's competitive home run derby number guessing minigame.

## What's in a name?

The name "DOAM" is a reference to the Foam Doam, the original ballpark that hosted Minor League Redditball games. The park itself had extremely offense-positive park factors that allowed for lots of home runs.

## Branches

main: This is the most current release version available - it is also the version of the bot that runs on the MLR Discord server, as well as other team Discord servers.

test: This is the development branch. Changes are merged to this branch for testing before being merged to main. This version of the bot runs exclusively on the DOAM testing Discord server.
